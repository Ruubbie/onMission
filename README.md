# On Mission

Tools for Ruben's move to YWAM Queenstown.

- `missions/app/ios`: the iPhone app (SwiftUI). It is built in the cloud by `.github/workflows/ios.yml`.
- `missions/app/windows`: the Windows desktop helper.
- `missions/app/server`: the sync server (Cloudflare Worker).
- `missions/app/api/openapi.yaml`: the API contract the apps share.
- `missions/app/design/tokens.json`: the shared design tokens.
