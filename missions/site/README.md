# hesent.me

The public website for Ruben's road to YWAM Queenstown. Built: the header, an interactive globe, My story, The journey, Letters, Get involved (with the sign-up), the giving page and the footer, on reusable tokens and components.

- **Dutch** at `/nl/`, **English** at `/en/`. The bare domain `/` picks one: the language the visitor chose before (the NL/EN switch sets a cookie), otherwise the browser's language, otherwise Dutch.
- The old Tomato Flood zine is kept unchanged in `legacy/` for reference.

## Design system

- `public/assets/tokens.css`: every colour, size, space, texture and motion value. Change a colour here, not in a component. `--container` is the width of the header and the page content alike. The globe reads its colours from the `--globe-*` tokens.
- Motion: things move on springs (`--ease-spring`, `--ease-bounce` in `tokens.css`, built with CSS `linear()`, falling back to ease-out). Buttons, pills and the logo give under a press and spring back; hover effects only apply with a real pointer, so a tap on a phone never leaves one stuck. The hero assembles itself on load, cards rise in as they scroll into view, server content settles in, a wrong sign-up field shakes, and the vision card, the letter and the prayer sheet tilt toward the mouse (`site.js`). The globe's fling coasts and slows in real time (the same at 60 and 120 Hz), a grab catches it, it rubber-bands past the poles, arrow keys glide, and the slow turn fades back in. With reduced motion none of this runs.
- `public/assets/components.css`: the reusable parts: section (a heading, never an eyebrow label above it or a stripe under it), button, logo, nav, language switch, art (a placed cut-out), header, globe, footer.
- `public/assets/site.css`: the home page layout (the hero and its illustration stage).
- Type: Archivo only, heavy and tight for headings, regular for reading. No serif, no handwriting (`public/assets/fonts/archivo.woff2`).
- Paper: `public/assets/texture/paper.webp`, a scanned-paper texture tiled over the whole page (`--texture-paper`). The letter card should use the same token.

## Illustrations

In `public/assets/art/`, transparent WebP in the reference style (ink line, flat grainy fills): `letters.webp` (the letters front page and the foot of a letter: a stack of airmail envelopes tied with string, a sprig and a coral flower; generated in Canva on 2026-10-27 with `suitcase.webp` as the style reference, background removed, exported at 1264 px and trimmed to 640 px), `traveller.webp` (cut off just below the jacket, with a thin paper-coloured edge where he overlaps the globe), `plants-left.webp`, `plants-right.webp` (the clusters at the foot of the globe, also used on the footer ridge), `mountains.webp`, `flower-coral.webp`, `flower-pink.webp`, `flower-sage.webp` (on the My story vision card), `jar.webp` (the giving page: a glass jar of coins with a paper heart, a luggage tag with a paper plane and a sprig; generated in Canva on 2026-10-28 with `suitcase.webp` as the style reference, the canvas cut away along the ink line, trimmed to 640 px), `suitcase.webp` (The journey; generated in Canva on 2026-10-27 with `traveller.webp` as the style reference, background removed, trimmed to 640 px). The logo is `public/assets/logo-192.webp` (header), `logo-512.webp` (footer, inverted to light) and `logo-192.png` (favicon).

They were generated in Canva from the reference design, cut out, trimmed and converted to WebP. To replace one, keep the file name and roughly the same proportions; the positions are percentages of the stage in `site.css`, measured from the reference so the globe, traveller and plants sit in the same proportions.

## Files

- `content/en.json`, `content/nl.json`: all the copy. `content/site.json`: domain, sync-server address, departure date.
- `src/page.mjs`: the home page's sections. `src/shell.mjs`: the head, header and footer every page shares, the two letter pages and the giving page. `src/world.mjs`: land outlines. `build.mjs` writes `public/nl/`, `public/en/` (each with the letters front page, the letter page and the giving page) and `public/assets/land.json` (the globe's land).

## Change text

Edit `content/nl.json` or `content/en.json`, then:

```
node build.mjs
```

## Try it locally

```
node dev.mjs
```

Open http://localhost:8788. The pages read the real server in `content/site.json`, just like the live site. Start it with `SAMPLE=1` and it answers the public API routes itself with sample data instead: seven letters in both languages with drawn stand-in photos, from `dev-letters.mjs` (start it with `LETTERS=0` to see the pages before any letter is online), sample bank details (`GIVING=0` to see Give before they are filled in), and sign-ups and giving-page messages are logged, not stored. Run `node build.mjs` first so `land.json` exists (it also takes the departure date from the server, falling back to `site.json`); without it the globe shows ocean, the route and the pins.

## Put it online

The site runs on your own server, behind nginx. After a change: run `node build.mjs`, copy `public/` to the server, and open https://hesent.me to check that it sends you to `/nl/` or `/en/`. Where the bare domain isn't answered by `src/worker.js`, `public/index.html` picks the language instead.

The letter pages are plain files too: a letter's address is `/nl/brief/?3-een-nieuw-hoofdstuk` (the part after the ?), so no server rules are needed.
